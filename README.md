# 🌈 SoMe Kids

En enkel og trygg «sosiale medier»-app for barn. Den kjører helt i nettleseren, uten server, uten innlogging og uten sporing. Alt lagres lokalt (localStorage).

## Kom i gang

Åpne `index.html` i en nettleser. Det er alt.

## Funksjoner

- **Profil med kallenavn og dyre-avatar.** Ingen ekte navn eller bilder.
- **Korte innlegg** (maks 140 tegn) med bakgrunnsfarge og klistremerke.
- **Bare positive reaksjoner** (❤️ ⭐ 😂 👏). Ingen «liker ikke», ingen følgere.
- **Snillfilter** som stopper stygge ord, telefonnumre, e-postadresser, adresser og lenker, med en vennlig forklaring.
- **«Si fra»-knapp** som skjuler et innlegg og sender det til foreldremodus.
- **Foreldremodus** med PIN-kode: se, gjenopprett eller slett rapporterte innlegg, bytt profil eller nullstill alt.
- **Skjermtidspåminnelse** etter 20 minutter.

## Tilpasning

I toppen av `app.js` kan du endre avatarer, klistremerker, farger, ordlisten (`BAD_WORDS`) og skjermtidsgrensen.
